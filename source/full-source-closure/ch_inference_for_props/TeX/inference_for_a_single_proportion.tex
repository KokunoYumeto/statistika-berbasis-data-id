\eoce{\qt{Kesetaraan gender\label{gender_equality}}
Survei Sosial Umum mengajukan pertanyaan berikut kepada sampel acak
sebanyak 1,390 warga Amerika:
``Secara umum, menurut Anda, apakah pemerintah semestinya atau tidak semestinya
bertanggung jawab untuk mendorong kesetaraan
antara laki-laki dan perempuan?''
Sebanyak 82\% responden menjawab ``semestinya''.
Pada tingkat kepercayaan 95\%, sampel ini memiliki batas galat 2\%.
Berdasarkan informasi ini, tentukan apakah pernyataan-pernyataan berikut
benar atau salah, dan jelaskan alasan Anda.\footfullcite{data:gss}
\begin{parts}
\item Kita yakin 95\% bahwa antara 80\% dan 84\% warga Amerika dalam 
sampel ini berpendapat bahwa pemerintah bertanggung jawab mendorong kesetaraan antara 
laki-laki dan perempuan.
\item Kita yakin 95\% bahwa antara 80\% dan 84\% seluruh warga Amerika 
berpendapat bahwa pemerintah bertanggung jawab mendorong kesetaraan antara 
laki-laki dan perempuan.
\item Jika kita mempertimbangkan banyak sampel acak yang masing-masing terdiri atas 1,390 warga Amerika, dan menghitung 
interval kepercayaan 95\% untuk setiap sampel, 95\% dari interval tersebut akan memuat 
proporsi populasi sebenarnya dari warga Amerika yang berpendapat bahwa pemerintah 
bertanggung jawab mendorong kesetaraan antara laki-laki dan perempuan.
\item Untuk mengurangi batas galat menjadi 1\%, kita perlu 
melipatgandakan ukuran sampel menjadi empat kali (mengalikannya dengan 4).
\item Berdasarkan interval kepercayaan ini, terdapat bukti yang cukup untuk 
menyimpulkan bahwa mayoritas warga Amerika berpendapat bahwa pemerintah bertanggung jawab 
mendorong kesetaraan antara laki-laki dan perempuan.
\end{parts}

% n = 1390
% should be: 1142
% p = 1142/1390 = 0.82
% me = sqrt(.82*.08/1390)*1.96 = 0.02
